SECUREATTEND - PRESENTATION COPY

This package contains the Project 1 files needed to run the college demonstration locally.

QUICK START (Windows PowerShell)
1. Open PowerShell in this folder.
2. Check that Python is installed: python --version
3. Create the virtual environment: python -m venv venv
4. Activate it: .\venv\Scripts\Activate.ps1
5. Install dependencies: pip install -r requirements.txt
6. Start the application: python app.py
7. Open in Chrome: http://127.0.0.1:5000
